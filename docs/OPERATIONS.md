## Operating cadence

1. A daily GitHub Actions workflow checks public page and download availability using HTTP GET only. It does not execute analytics or simulate users. It runs only while this repository is public and stops making requests after the trial window.
2. The existing desktop-thread heartbeat reviews evidence daily when its host is available: availability, real analytics, genuine issues, merchant verification and actual transactions if payment becomes available.
3. Keep an evidence log of dates, status and real blockers. Do not interpret missing metrics as zero.
4. Make fixes driven by reproducible defects or genuine feedback. Do not manufacture commits merely to keep a scheduler alive.
5. At trial end report visits, qualified requests, paid orders, refunds, fees and bank settlements separately. State unavailable figures as unknown and stop recurring trial work.

GitHub scheduling can be delayed, and GitHub may disable scheduled runs after 60 days of repository inactivity. The desktop heartbeat should check the workflow state and, if necessary, re-enable it within the authorized trial. This workflow is availability monitoring, not an independent sales or customer-support agent. The desktop heartbeat requires the local host/app.

## Commercial readiness

An optional template product remains in preparation. Opening a merchant account is not evidence of sales, successful settlement or completion of identity review.

Before adding any purchase button:

- Finish the actual product and test every file, language, sample and promised output.
- Publish accurate seller/contact, price, delivery, usage and refund information suitable for the intended offer and jurisdiction.
- Verify merchant review and available payment methods directly.
- Test success, failure, cancellation and delivery. A public success/download URL is not payment verification.
- Use a real authorized checkout with no monthly add-ons. Do not put a secret key in a static website or repository.
- Reconcile actual payment, fees, refunds and bank settlement before describing revenue as received.

The free MIT core is not contingent on buying extras.
